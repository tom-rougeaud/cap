# Σ Maths · CAP

L’appli et le manuel de mathématiques **Maths · CAP**, pour les classes préparant au CAP (programme du BOEN spécial n° 5 du 11 avril 2019).

👉 En ligne : https://tom-rougeaud.github.io/cap/

- **10 chapitres** : statistique à une variable · probabilités · proportionnalité · pourcentages et échelles · équations et formules · fonctions et graphiques · fonctions linéaires et affines · calculs commerciaux ➕ · périmètres, aires et volumes ➕ · Pythagore, Thalès et trigonométrie ➕ (➕ : domaine propre à un groupement de CAP)
- **Une notion, une page** : 🔎 Je découvre → 🧭 La méthode → ✅ La solution → 📌 Je retiens → ✏️ À moi ; la page « Je fais le point » porte 10 automatismes sans calculatrice
- Situations de **pop culture avec des données réelles sourcées** (Les Simpson, cinéma en France, Netflix, statue de l’Unicorn Gundam, football…) ; un **métier par chapitre** avec ses formations
- **Exercices à trois niveaux** (🌱 guidé · courant · 🚀 défi) dont les nombres changent à chaque essai, problèmes « vers le CCF », simulateur « Je manipule » avec un défi, programmes Scratch
- Chaque chapitre se termine par une **évaluation sur 10 au format du CCF** (45 minutes) ; **3 CCF blancs** avec chrono dans l’appli, et en PDF ; une **fiche de révision** A4 par chapitre
- Graphiques lisibles : lignes de lecture, valeurs écrites sur les diagrammes, secteurs séparés par des traits noirs
- Installable sur l’écran d’accueil (Android : bannière ; iPhone et iPad : Partager → « Sur l’écran d’accueil »)
- Progression enregistrée **uniquement sur l’appareil** (export / import / effacement), aucune donnée envoyée ; un seul fichier HTML, sans CDN ni police externe

## Contenu du dépôt
- `index.html` : l’appli, en un seul fichier ; `manifest.webmanifest`, `sw.js` et les icônes : l’installation sur l’écran d’accueil
- `pdf/maths-cap.pdf` : le manuel élève ; `pdf/chapitres/` : un PDF par chapitre et les CCF blancs ; `pdf/fiches-de-revision-maths-cap.pdf`
- `sources/` : les fichiers qui fabriquent le manuel et l’appli (voir `sources/README.md`)

La version professeur (réponses et corrigés détaillés) n’est pas publiée ici.

Les autres niveaux : [3ème Série Pro](https://tom-rougeaud.github.io/3eme/) · [2de, 1re, Tle](https://tom-rougeaud.github.io/mcv/).

Les chiffres suivis d’une source sont réels et datés ; tout le reste (boutiques, prix, taux, enquêtes, personnages) est inventé pour les exercices, comme le rappelle le début du manuel.
